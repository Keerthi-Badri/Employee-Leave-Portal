\# Employee Leave Management System



A Flask-based Employee Leave Management System that helps employees apply for leaves and managers approve or reject leave requests.



\## Technologies Used



\- Python

\- Flask

\- MySQL

\- HTML

\- CSS

\- JavaScript



\## Features



\- Employee registration and login

\- Employee leave request submission

\- Manager leave approval/rejection

\- Leave balance tracking

\- Approved leave management



\## Project Structure



\- app.py - Flask backend

\- templates/ - HTML pages

\- static/ - CSS and JavaScript files



\## Database



MySQL database with tables:

\- users

\- leave\_requests

\- approved\_leave
